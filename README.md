# 智慧学习整理系统

智慧学习整理系统是一个全学科学习管理平台，支持小学、初中、高中、大学的所有学科，提供知识归纳、必背必记、学习笔记、错题整理、母题整理、分数历史比对、同考点题目归拢、模拟测试和做题模式等功能。

## 功能特性

### 核心功能
- **全学科分类**：支持小学、初中、高中、大学的所有学科
- **知识归纳**：管理和整理知识点，支持图片和学科符号
- **必背必记**：管理需要记忆的内容，跟踪记忆进度
- **学习笔记**：记录和管理学习笔记
- **错题整理**：收集和分析错题，提供针对性练习
- **母题整理**：整理母题，掌握解题技巧
- **分数历史**：记录和分析分数趋势
- **同考点归拢**：将相同考点的题目归类
- **模拟测试**：进行模拟考试，评估学习效果
- **做题模式**：提供针对性的练习模式

### 高级功能
- **自动思维导图**：根据知识点自动生成思维导图
- **学习分析**：分析学习情况，识别薄弱环节
- **跨平台支持**：支持 Windows、安卓和麒麟系统
- **离线使用**：支持离线访问和本地存储
- **响应式设计**：适配不同屏幕尺寸

## 技术栈

- **前端框架**：React 18 + TypeScript + Tailwind CSS + Vite
- **状态管理**：Zustand
- **路由**：React Router
- **数据可视化**：Recharts
- **跨平台支持**：PWA (Progressive Web App)
- **数据存储**：LocalStorage 持久化
- **后端**：Express.js (可选)

## 安装和使用

### 开发环境
1. **克隆仓库**
   ```bash
   git clone https://github.com/dch520438/smart-learning-system.git
   cd smart-learning-system
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动开发服务器**
   ```bash
   npm run dev
   ```

4. **访问应用**
   在浏览器中打开 `http://localhost:5174`

### 生产环境
1. **构建项目**
   ```bash
   npm run build
   ```

2. **部署**
   - 将 `dist` 目录部署到任何静态网站服务器
   - 或使用 `npm run preview` 预览生产版本

### PWA 安装
- **Windows**：在 Chrome 或 Edge 浏览器中打开应用，点击地址栏右侧的 "安装" 按钮
- **安卓**：在 Chrome 浏览器中打开应用，点击菜单按钮，选择 "添加到主屏幕"
- **麒麟系统**：在支持 PWA 的浏览器中打开应用，按照浏览器提示安装到桌面

## 新功能说明

### 1. 搜索功能
- **位置**：导航栏顶部的搜索框
- **功能**：搜索知识点、笔记、题目和必背内容，按类型分类显示结果
- **使用方法**：在搜索框中输入关键词，系统会自动按类型分类显示相关结果
- **特点**：
  - 按类型分类显示（知识点、笔记、题目、必背内容）
  - 每个分类最多显示5个结果
  - 点击结果直接跳转到对应页面

### 2. 必背必记检测
- **位置**：必背必记页面中每个内容的测试按钮
- **功能**：测试用户对必背内容的记忆程度
- **使用方法**：点击测试按钮，选择文字或语音输入模式，输入答案后提交

### 3. 试卷整理
- **位置**：导航栏中的"试卷收集"选项
- **功能**：通过拍照或上传方式收集学校做过的试卷
- **使用方法**：点击"添加试卷"按钮，填写试卷信息，可选择拍照或上传图片

### 4. 手动添加分数记录
- **位置**：分数历史页面中的"添加记录"按钮
- **功能**：手动录入学校测试分数，用于分析
- **使用方法**：点击"添加记录"按钮，填写测试信息和分数

### 5. 数据抓取与导入
- **位置**：导航栏中的"数据抓取"选项
- **功能**：提供学习资源网站链接和数据添加建议
- **重要说明**：
  - 大多数教育网站有反爬虫机制，不建议直接爬取
  - 请尊重网站的使用条款和知识产权
  - 推荐使用手动输入、复制粘贴或拍照上传的方式添加内容
- **内置网站**：
  - 知识点学习网站：百度百科、维基百科、中国教育资源网、学习强国
  - 试题练习网站：猿题库、菁优网、学科网、21世纪教育网

### 6. 知识页面优化
- **位置**：知识归纳页面
- **功能**：管理知识点，支持分类和标签筛选
- **特点**：
  - 按标签筛选知识点
  - 支持排序（最新修改、最早创建、按标题排序）
  - 卡片式布局，带有悬停效果
  - 图片预览功能
  - 标签可点击，点击后自动筛选

### 7. 笔记页面优化
- **位置**：学习笔记页面
- **功能**：管理学习笔记，支持分类和标签筛选
- **特点**：
  - 按分类筛选（普通笔记、学习方式、学习技巧、学习习惯）
  - 按标签筛选笔记
  - 支持排序（最新修改、最早创建、按标题排序）
  - 卡片式布局，带有分类图标和悬停效果
  - 图片预览功能

## 数据来源

本应用是一个本地学习管理系统，所有数据均由用户手动添加，不自动从任何网站收集知识和题目。用户可以根据自己的学习需求，手动录入知识点、题目、笔记等内容。

## 使用说明

1. **选择学科**：在首页选择年级和学科
2. **管理知识**：在知识归纳页面添加和管理知识点
3. **记忆检测**：在必背必记页面添加需要记忆的内容，并使用测试功能检测记忆效果
4. **记录笔记**：在学习笔记页面记录学习心得和重点
5. **整理错题**：在错题整理页面收集和分析错题
6. **模拟测试**：在模拟测试页面进行练习
7. **分析分数**：在分数历史页面查看分数趋势，可手动添加分数记录
8. **收集试卷**：在试卷收集页面通过拍照或上传方式收集学校试卷
9. **搜索内容**：使用导航栏的搜索功能快速查找内容
