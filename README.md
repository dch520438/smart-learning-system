# 智慧学习整理系统

智慧学习整理系统是一个全学科学习管理平台，支持小学、初中、高中、大学的所有学科，提供知识归纳、必背必记、学习笔记、错题整理、母题整理、分数历史比对、同考点题目归拢、模拟测试和做题模式等功能。

## 功能特性

### 核心功能
- **全学科分类**：支持小学、初中、高中、大学的所有学科
- **知识归纳**：管理和整理知识点，支持图片和学科符号
- **必背必记**：管理需要记忆的内容，跟踪记忆进度，支持语音检测
- **学习笔记**：记录和管理学习笔记
- **错题整理**：收集和分析错题，提供针对性练习
- **母题整理**：整理母题，掌握解题技巧
- **分数历史**：记录和分析分数趋势，支持编辑和删除记录
- **同考点归拢**：将相同考点的题目归类
- **模拟测试**：进行模拟考试，评估学习效果
- **做题模式**：提供针对性的练习模式

### 高级功能
- **自动思维导图**：根据知识点自动生成思维导图，关联必记必背和母题
- **学习分析**：分析学习情况，识别薄弱环节
- **跨平台支持**：支持 Windows、安卓和麒麟系统（通过 PWA）
- **离线使用**：支持离线访问和本地存储，所有数据本地保存
- **响应式设计**：适配不同屏幕尺寸
- **隐藏式导航**：导航栏和搜索栏默认隐藏，点击箭头显示
- **打印功能**：支持打印知识、必记必背、错题、母题等内容

## 技术栈

- **前端框架**：React 18 + TypeScript + Tailwind CSS + Vite
- **状态管理**：Zustand（带 LocalStorage 持久化）
- **路由**：React Router
- **数据可视化**：Recharts
- **跨平台支持**：PWA (Progressive Web App)
- **数据存储**：LocalStorage 持久化
- **后端**：Express.js (可选)

## 安装和使用

### 开发环境
1. **克隆仓库**
   ```bash
   git clone https://github.com/dch520438/smart-learning-system.git
   cd smart-learning-system
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动开发服务器**
   ```bash
   npm run dev
   ```

4. **访问应用**
   在浏览器中打开 `http://localhost:5174/smart-learning-system/`

### 生产环境
1. **构建项目**
   ```bash
   npm run build
   ```

2. **部署**
   - 将 `dist` 目录部署到任何静态网站服务器
   - 或使用 `npm run preview` 预览生产版本

### PWA 安装
- **Windows**：在 Chrome 或 Edge 浏览器中打开应用，点击地址栏右侧的 "安装" 按钮
- **安卓**：在 Chrome 浏览器中打开应用，点击菜单按钮，选择 "添加到主屏幕"
- **麒麟系统**：在支持 PWA 的浏览器中打开应用，按照浏览器提示安装到桌面

## 新功能说明

### 1. 隐藏式导航栏
- **位置**：页面左上角（导航箭头）和右上角（搜索图标）
- **功能**：默认隐藏导航栏和搜索栏，点击箭头显示
- **使用方法**：
  - 点击左上角箭头显示/隐藏导航栏
  - 点击右上角搜索图标显示/隐藏搜索栏
- **特点**：节省屏幕空间，提供更大的阅读区域

### 2. 分数历史编辑和删除
- **位置**：分数历史页面的每条记录右侧
- **功能**：编辑和删除已添加的分数记录
- **使用方法**：
  - 点击编辑按钮修改记录内容
  - 点击删除按钮删除记录（需确认）
- **特点**：分数和时间支持任意数字输入，包括小数

### 3. 打印功能
- **位置**：各功能页面的操作栏
- **功能**：打印知识、必记必背、错题、母题、分析、思维导图等内容
- **使用方法**：选择要打印的内容类型，点击打印按钮
- **特点**：
  - 支持多种内容类型选择
  - 优化打印布局
  - 支持打印预览

### 4. 搜索功能
- **位置**：右上角搜索图标（隐藏式）
- **功能**：搜索知识点、笔记、题目和必背内容
- **特点**：
  - 按类型分类显示结果
  - 点击结果直接跳转

### 5. 必背必记语音检测
- **位置**：必背必记页面
- **功能**：测试用户对必背内容的记忆程度，支持语音输入
- **特点**：
  - 支持文字和语音两种输入模式
  - 使用 Levenshtein 距离算法计算准确率
  - 填空模式随机抠取完整词语

### 6. 填空题模式优化
- **位置**：必背必记测试功能
- **功能**：随机抠取完整词语作为填空内容
- **特点**：
  - 不抠标点符号
  - 每次使用时抠空位置不同
  - 扣空内容为完整词语或句子

### 7. 卡片展示效果
- **位置**：知识归纳、笔记等页面
- **功能**：正方形卡片展示，带有堆叠效果
- **特点**：
  - 统一的正方形尺寸
  - 阴影层次堆叠效果
  - 悬停动画效果

### 8. 数据抓取功能
- **位置**：导航栏中的"数据抓取"选项
- **功能**：提供学习资源网站链接
- **内置网站**：
  - 百度百科、维基百科、豆包、知乎
  - 中小学智慧教育平台

## 数据来源

本应用是一个本地学习管理系统，所有数据均由用户手动添加，不自动从任何网站收集知识和题目。用户可以根据自己的学习需求，手动录入知识点、题目、笔记等内容。

## 使用说明

1. **选择学科**：在首页选择年级和学科
2. **管理知识**：在知识归纳页面添加和管理知识点
3. **记忆检测**：在必背必记页面添加需要记忆的内容，并使用测试功能检测记忆效果
4. **记录笔记**：在学习笔记页面记录学习心得和重点
5. **整理错题**：在错题整理页面收集和分析错题
6. **模拟测试**：在模拟测试页面进行练习
7. **分析分数**：在分数历史页面查看分数趋势，可手动添加、编辑、删除分数记录
8. **收集试卷**：在试卷收集页面通过拍照或上传方式收集学校试卷
9. **搜索内容**：点击右上角搜索图标快速查找内容
10. **使用导航**：点击左上角箭头显示/隐藏导航栏

## 数据持久化

应用使用 LocalStorage 进行数据持久化，所有数据存储在浏览器本地，无需后端服务即可使用。数据会自动保存，刷新页面后数据不会丢失。
